# ThirdParty_API_Challenge

This is a project that uses a API Key from RAWG Video Games Database

Its a search website that uses the RAWG API to search for video game titles and genres.

# Features:
- Searches using RAWG Video Games Database for games
- Can search for either title or genre
- Has thumbnails for each game if available
- Leads users to the RAWG website for the game
# Prerequisites
You'll need a RAWG Video Games Database API key to run this project.

Make a local config.js file and add your API key:

const RAWG_API_KEY= "YOUR_API_KEY_HERE";

A config.sample.js file is included as a template for creating your own config.js.

# Running Locally
Clone the repository:
git clone git@github.com:YOUR-USERNAME/YOUR-REPOSITORY.git

Open the project folder.

Create config.js by copying config.sample.js.

Replace the placeholder API key with your real RAWG API key.

Open index.html in your browser.

The website should now be ready to use. Enjoy!
